AI video skill for Claude Code & Codex — cinematic, editable product promos with Remotion.

## Installation

1. Install Python dependencies: `pip install fastapi uvicorn`
2. Install Node.js dependencies: `cd frontend && npm install`
3. Run the backend: `uvicorn app.main:app --host 0.0.0.0 --port 8000`
4. Run the frontend: `cd frontend && npm start`

## Usage

Visit the UI at http://localhost:3000 to explore shot recipes and video editing features.
